SatiDotNet2 Developer Documentation

Welcome! This documentation is designed to help new developers understand the SatiDotNet2 codebase, particularly the surf scan reporting and data collection systems.

Quick Start

SatiDotNet2 is a web application for managing wafer manufacturing data, including surface scan inspection reports, label printing, and SPC analysis.

Surf Scan Tools Overview

The application supports multiple surf scan tools that inspect wafer surfaces for defects and particles:

Tool Machine ID Data Collection Method
SP1 SP1 Linked Server + Stored Procedure
SP1-3 SP1-3 Linked Server + Stored Procedure
SP2 SP2-S0132 SP2DC Software (Real-time)
SP3-1 SP3-2110224 SP2DC Software
SP3-2 SP3-2110164 SP2DC Software
SP5-1 SP5-2130406 SP2DC Software
Important: SP1 and SP1-3 tools collect data differently than SP2, SP3, and SP5 tools. SP1/SP1-3 use SQL Server linked servers and stored procedures to sync data on-demand, while the other tools use the SP2DC data collection software which uploads data directly to the database.

Key Concepts

SP1_Data Table

The central cache table that stores all surf scan inspection data from all tools. The web application reads from this table for reporting and analysis.

Location: AutoData.dbo.SP1_Data

Archive: AutoData.dbo.Archive_SP1_Data (data older than 90 days)

Data Refresh (SP1 & SP1-3 only)

For SP1 and SP1-3 tools, users must trigger a data refresh to sync the latest data from the tool systems. This is done via "Update" buttons in the application or automatically before certain operations.

The refresh calls stored procedures like [exsil_user].[SP1DataCollector_SP11Only] which query the tool database via linked server and insert new records.

View Details

Bin Fall Report

The primary report for viewing surf scan session results. Shows pass/reject counts, allows filtering by tool, date range, wafer diameter, and more. Includes drill-down to individual wafer data and map images.

Location: Reports/SurfScan.aspx
